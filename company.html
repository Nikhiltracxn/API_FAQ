Search by PINCODE and get the companies in that PINCODE

Category: Company  |  Created: 2025-06-16

The user can use the below Sample request to search via PINCODE: { "sort": [ { "sortField": "relevance", "order": "DEFAULT" } ], "filter": { "addressesType": [ "Headquarters", "Other Offices" ], "addressesPinCode": [ "560102" ] } }
